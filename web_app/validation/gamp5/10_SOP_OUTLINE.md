# 10 — Required SOP Outline (Procedural Controls)

Create and approve the following SOPs under your Quality System:

1. **SOP-IPA-ACCESS** — User account creation, role assignment, disable/lockout, password reset  
2. **SOP-IPA-BACKUP** — MongoDB + `storage/` backup, restore test, retention (7 years)  
3. **SOP-IPA-CHANGE** — Software release and model weight change control  
4. **SOP-IPA-DEVIATION** — Incident / deviation / CAPA for analysis errors  
5. **SOP-IPA-TRAINING** — Operator / reviewer / QA training curriculum  
6. **SOP-IPA-AUDIT** — Periodic review of `system_audit`  
7. **SOP-IPA-TIME** — Server time synchronization (NTP)  
8. **SOP-IPA-ANALYSIS** — Procedure for AI run → human review → e-signed publish  

Attach approved SOP numbers to the Validation Summary Report.
